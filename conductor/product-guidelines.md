# Product Guidelines

Keep row identifiers, currency units, scenario assumptions and error messages
explicit. Preserve nulls, deterministic seed handling and reproducible output
filenames. Reports must agree with their underlying tables.

Distinguish implementation, synthetic tests, workbook reconciliation, statistical
acceptance and hosted CI. Record the exact source revision and evidence scope;
a passing tool or installed CLI help check does not establish scientific parity.

Keep original workbooks, generated outputs, private logs and screening receipts
with their existing owner. Source integration must exclude these artifacts.
Use plain language in documentation and leave a blank line before each heading.
