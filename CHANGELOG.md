### Added
- Created `data/formulas.json` to begin abstracting the calculation logic. This file defines the parameters and mathematical expressions for the core cost calculation, moving the logic out of the Python code.
- Initial project setup.
- `ruff` for linting and formatting.
- `pytest` for testing.
- `pipenv` for dependency management.
- `pre-commit` for automated checks.
- `mypy` for static type checking.
- `bandit` for security analysis.
- `tox` for testing in multiple environments.
- `pytest-cov` for code coverage.
- `.editorconfig` for consistent coding styles.
- GitHub templates for issues and pull requests.
- `LICENSE`, `CHANGELOG.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`.
- `dependabot` for automated dependency updates.
- `commitizen` for automated versioning and changelog management.
- `Sphinx` for automated documentation generation.
